# Clickable prototype — 21 September 2026

`index.html` is a single self-contained file: open it in a browser. It shows the four version-1 screens (products grid with category tree, variations expanded and flat, the three-step bulk change flow with preview, and history with undo and conflict handling), plus Settings, and Normal / Loading / Empty / Error states through the switcher at the bottom right. Fake data, no network requests.

Made from three independent design candidates (WordPress-native, workspace, guided) judged by three lenses, then merged and verified over five fix rounds. Candidate files and judge screenshots were kept out of the repo.
