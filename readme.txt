Manage many WooCommerce products at once. Every bulk change is previewed first, recorded and reversible.

== Description ==

Bulk Catalogue Manager adds one simple screen under Products for changing many products and variations at once. It edits WooCommerce's own product data only and works on a plain WooCommerce shop with nothing else installed.

This plugin is in early development. The editing screen is not available yet.

== Installation ==

1. Install and activate WooCommerce 10.0 or later.
2. Upload the `bulk-catalogue-manager-for-woocommerce` folder to `/wp-content/plugins/`, or install the ZIP from Plugins → Add New → Upload Plugin.
3. Activate the plugin.
